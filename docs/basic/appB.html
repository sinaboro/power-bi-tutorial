부록 B. 용어 풀이

용어 풀이
Power BI Desktop 내 PC 에서 데이터를 불러와 보고서를 만드는 무료 프로그램 (Windows 전용)
Power BI 서비스 만든 보고서를 웹(app.powerbi.com)에 올려 공유하는 곳. 회사·학교 계정 필요
.pbix Power BI Desktop 파일. 불러온 데이터·정리 단계·모델·보고서가 모두 들어 있다
보고서 / 페이지 시각적 개체를 올려놓은 화면 묶음 / 그 안의 한 장 (아래쪽 탭)
대시보드 핵심 숫자와 차트를 한눈에 보이게 모은 화면. 이 과정에서는 보고서 페이지로 만든다
시각적 개체 (visual) 캔버스에 올리는 모든 것 - 차트, 표, 카드, 슬라이서, 텍스트 상자
캔버스 시각적 개체를 올려놓는 가운데 흰 영역
보고서 / 테이블 / 모델 보기 차트를 만드는 화면 / 데이터를 표로 확인하는 화면 / 테이블 관계를 보는 화면
CSV 값을 쉼표로 나눠 적은 글자 파일
UTF-8 한글 등 모든 글자를 저장하는 문자 인코딩. CSV 를 불러올 때 맞춰야 한글이 안 깨진다
Power Query 데이터를 불러오고 정리하는 도구 (Power Query 편집기)
쿼리 Power Query 에서 테이블 하나를 만드는 작업 묶음
적용된 단계 쿼리에서 한 작업 기록. 새로 고침할 때마다 처음부터 다시 실행된다
M Power Query 가 단계를 적는 언어. 수식 입력줄에 보인다 (읽기만 해도 된다)
null 값이 없음 (빈칸)
데이터 형식 열 값의 종류 - 정수, 10진수, 텍스트, 날짜, 날짜/시간 등
새로 고침 원본 파일을 다시 읽고 모든 정리 단계와 계산을 다시 하는 것
데이터 모델 불러온 테이블들과 그 사이의 관계, 측정값을 합친 것
사실(Fact) 테이블 사건(주문·판매)마다 한 줄씩 쌓이는 표. 숫자가 있다 (판매)
차원(Dimension) 테이블 무엇으로 나눠 볼지 설명하는 표 (메뉴, 매장, 날짜)
별 모양(스타) 스키마 사실 테이블을 가운데 두고 차원 테이블을 둘러 연결한 모델 모양
관계 두 테이블의 같은 값(키)을 잇는 선. 필터가 그 선을 따라 흐른다
카디널리티 관계의 종류 - 일대다(1:*), 일대일(1:1), 다대다(*:*)
키 행을 구분하는 값 (메뉴코드, 매장코드, 날짜)
날짜 테이블 하루에 한 줄씩 있는 달력 표. 연도·월·요일 등으로 나눠 보게 한다
DAX Power BI 의 계산 식 언어. 측정값·계산 열·계산 테이블을 만든다
계산 열 행마다 값을 계산해 표에 저장하는 열 (연도 = YEAR('날짜'[Date]))
측정값 보고서에서 보는 자리의 조건으로 그때그때 계산되는 식 (총매출 = SUM('판매'[매출액]))
암시적 측정값 숫자 열을 끌어다 놓았을 때 자동으로 생기는 합계·개수
필터 컨텍스트 측정값을 계산할 때 걸려 있는 조건 (행렬의 행, 슬라이서, 차트 클릭 등)
SUM / DISTINCTCOUNT / COUNTROWS / DIVIDE 합계 / 서로 다른 값의 개수 / 행 수 / 0 으로 나눠도 안전한 나누기
카드 숫자 하나를 크게 보여 주는 시각적 개체
행렬 엑셀 피벗 테이블처럼 행·열로 나눠 숫자를 보여 주는 시각적 개체
슬라이서 보는 사람이 눌러서 거르는 필터 단추
상호 작용 한 시각적 개체를 누르면 같은 페이지의 다른 개체가 함께 걸러지는 것
표시 단위 큰 숫자를 천·백만 등으로 줄여 보여 주는 서식 (자동 / 없음 / 천 / 백만 …)
테마 보고서 전체의 색·글꼴을 정한 설정. JSON 파일로 불러올 수 있다
객단가 주문 한 번에 평균 얼마를 썼는지 = 총매출 ÷ 주문수
