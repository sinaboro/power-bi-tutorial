# 부록 A. 자주 만나는 문제와 해결

## A-1. 설치·파일 열기

| 증상 | 원인 | 해결 |
|---|---|---|
| 처음 실행할 때 로그인 창이 뜬다 | Power BI 서비스용 로그인 안내 | 이 과정은 로그인하지 않아도 된다. X 로 닫는다 |
| 완성 파일(.pbix)을 열었는데 화면은 나오지만 **새로 고침** 하면 "파일을 찾을 수 없습니다" | 실습 폴더가 `C:\study\power-bi-tutorial` 이 아니다 | 폴더를 그 위치로 옮기거나, **홈 → 데이터 변환 ▾ → 데이터 원본 설정 → 원본 변경** 에서 파일 경로를 내 위치로 바꾼다 |
| .pbix 를 두 번 눌러도 Power BI 가 안 열린다 | 파일 연결이 안 됨 | Power BI Desktop 을 먼저 실행하고 **파일 → 열기 → 이 장치 찾아보기** |
| "이 파일은 최신 버전의 Power BI Desktop 에서 만들어졌습니다" | 내 Power BI 가 오래됨 | Microsoft Store 에서 업데이트한다 |

## A-2. 데이터 불러오기·Power Query

| 증상 | 원인 | 해결 |
|---|---|---|
| CSV 의 한글이 `ì¹´íŽ˜` 처럼 깨진다 | 파일 원본이 UTF-8 이 아님 | 미리 보기에서 **파일 원본 → 65001: 유니코드(UTF-8)**. 이미 불러왔다면 Power Query 의 `원본` 단계 톱니바퀴에서 바꾼다 |
| 모든 값이 열 하나에 붙어 있다 | 구분 기호가 틀림 | 미리 보기에서 **구분 기호 → 쉼표** |
| 열 이름이 `Column1`, `Column2` | 첫 줄이 머리글로 올라가지 않음 | Power Query **홈 → 첫 행을 머리글로 사용** |
| 숫자 열의 값이 왼쪽 정렬되고 합계가 안 된다 | 형식이 텍스트 | 열 머리글의 형식 아이콘 → **정수** |
| 값 바꾸기를 했는데 일부가 그대로 | 대소문자·빈칸이 다름 (`Card`, `카드 `) | 값 목록(열 머리글 ▾)으로 실제 값을 확인하고 하나씩 바꾼다. 빈칸은 **공백 제거** 먼저 |
| 단계를 잘못 만들었다 | - | 적용된 단계에서 그 단계 왼쪽의 ✕. 설정만 바꾸려면 단계 오른쪽 톱니바퀴 |
| 중간 단계를 지웠더니 아래 단계들에 노란 경고(오류) | 아래 단계가 지운 단계의 결과(열 이름 등)를 쓰고 있었음 | 오류가 난 단계를 눌러 내용을 확인하고 다시 만든다. 단계는 **맨 아래부터** 지우는 것이 안전하다 |
| 닫기 및 적용이 아주 오래 걸린다 | 36만 줄을 다시 읽는 중 | 정상. 기다린다. (작업 중에는 Power Query 미리 보기만 보고, 적용은 마지막에 한 번) |

## A-3. 관계·DAX

| 증상 | 원인 | 해결 |
|---|---|---|
| DAX 식에 "잘못된 토큰" 오류 (`판매[수량]` 근처) | 한글 테이블 이름을 따옴표 없이 씀 | `'판매'[수량]` 처럼 작은따옴표로 감싼다 |
| "열 '…' 을(를) 찾을 수 없습니다" | 열·측정값 이름 오타, 다른 테이블의 열 | 수식 입력줄에서 `'` 나 `[` 를 쳐서 나오는 자동 완성 목록에서 고른다 |
| 관계를 만들 때 "카디널리티가 다대다" 경고 | 일(1) 쪽 표에 같은 키가 두 번 있음 (메뉴 중복) | 2장 2-4 의 중복 제거를 했는지 확인한다 |
| 행렬의 모든 칸에 같은 숫자 | 관계가 없거나 엉뚱한 열끼리 이어짐 | 모델 보기에서 선을 확인. 선을 두 번 눌러 어느 열끼리 이었는지 본다 |
| 요일이 금, 목, 수 … 순서로 나온다 | 열 기준 정렬을 안 함 | 3장 3-5. **열 도구 → 열 기준 정렬 → 요일번호** |
| 측정값이 엉뚱한 테이블에 들어갔다 | 새 측정값을 누를 때 다른 테이블이 선택돼 있었음 | 측정값을 고르고 **측정 도구 → 홈 테이블** 을 판매로 바꾼다 |
| 객단가 칸에 아무것도 안 나온다 | 주문수가 0(그 조건에 판매가 없음) | 정상. `DIVIDE` 는 0 으로 나눌 때 빈칸을 돌려준다 |

## A-4. 차트·보고서

| 증상 | 원인 | 해결 |
|---|---|---|
| 아이콘을 눌렀는데 새 차트가 안 생기고 기존 차트가 바뀌었다 | 차트가 선택된 상태였음 | **Ctrl+Z** 로 되돌리고, 캔버스 빈 곳을 누른 뒤 아이콘을 누른다 |
| 숫자가 `2십억`, `0.87십억` 으로 보인다 | 표시 단위가 **자동** | 서식 창에서 **표시 단위 → 없음** 또는 **백만** (6장 6-3) |
| 월별 꺾은선의 X축 이름이 `2023-…` 로 잘린다 | 글자 열(연월)을 축에 씀 | 날짜 형식 열(**월시작일**)을 쓴다 (5장 5-3) |
| 숫자 열을 넣었더니 합계가 아니라 개수가 나온다 | 열의 요약 방식이 개수 | 필드 칸에서 그 필드의 ▾ → **합계**. 또는 측정값을 만들어 쓴다 |
| 슬라이서를 바꿨는데 어떤 차트는 그대로 | 상호 작용이 꺼져 있음 | 슬라이서를 고르고 **서식 → 상호 작용 편집** 에서 그 차트의 필터 아이콘을 켠다 |
| 다른 페이지의 슬라이서가 따로 논다 | 동기화 안 됨 | **보기 → 슬라이서 동기화** 창에서 페이지를 체크 |
| 시각적 개체에 "하나 이상의 필드에 문제가 있습니다" | 쓰던 열·측정값의 이름을 바꾸거나 지움 | **이 항목 수정** → 필드를 다시 넣는다 |
