Power BI 기초

가상의 카페 하루커피의 3년치 매출 데이터를 정리하고 분석해 매출 대시보드를 완성하는 약 20시간 과정입니다. 처음 배우는 학생도 혼자 따라 할 수 있도록 모든 단계를 실제 화면과 함께 설명합니다.

교안 읽기 시작 → PDF 교안 (49쪽) 2단계 심화 (Olist) → 실습 파일 전체 받기 (ZIP)

시작하기

Windows PC 와 Power BI Desktop(무료)만 있으면 됩니다.

  1. Power BI Desktop 설치 - Microsoft Store 에서 "Power BI Desktop" 을 검색해 설치합니다.
  2. 실습 파일 받기 - ZIP 파일을 받아 C:\study 에 풀고, 폴더 이름을 power-bi-tutorial 로 바꿉니다. 완성 파일이 C:\study\power-bi-tutorial\data 의 데이터를 읽도록 만들어져 있습니다.
  3. 0장부터 차례로 - 각 장은 "학습 목표 → 따라 하기 → 정리 → 확인 문제" 순서입니다. 답은 부록 C 에 있습니다.

과정 목차

1~7장은 카페 데이터로 대시보드를 완성하고, 8장 과제에서 편의점 데이터로 혼자 만들어 봅니다.
