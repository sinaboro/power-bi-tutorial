# 부록 A. 자주 만나는 오류와 해결

## Power Query

| 증상 | 원인 | 해결 |
|---|---|---|
| "DataPath 을(를) 찾을 수 없습니다" | 매개 변수 이름이 다르다 (대소문자, 빈칸) | 쿼리 목록의 매개 변수 이름과 식의 이름을 똑같이 |
| "파일을 찾을 수 없습니다" (매개 변수를 쓴 뒤) | DataPath 값이 틀렸거나, `&` 뒤 파일 이름 앞에 `\` 가 빠졌다 | 홈 → 데이터 변환 ▾ → 매개 변수 편집 으로 값 확인. 식은 `DataPath & "\파일이름.csv"` |
| 다른 PC 에서 완성 파일을 열었더니 새로 고침 오류 | 그 PC 의 폴더가 다르다 | **매개 변수 편집** 에서 DataPath 를 그 PC 의 `…\data\olist` 경로로 바꾼다 |
| 리뷰 행 수가 100,000 보다 많다, review_score 에 글자가 섞였다 | 따옴표 안 줄 바꿈을 새 행으로 읽었다 | 원본 단계 `QuoteStyle.None` → `QuoteStyle.Csv`, 또는 톱니바퀴 → 줄 바꿈 **따옴표 붙은 줄 바꿈 무시** (2-2) |
| 병합 후 확장한 열이 모두 null | 키 열의 값이 서로 다르다 (형식, 앞뒤 빈칸, 대소문자) | 두 테이블의 키 열 형식을 같게(텍스트), 공백 제거 |
| 확장한 열 이름이 `고객.customer_state` 처럼 길다 | **원래 열 이름을 접두사로 사용** 이 켜져 있었다 | 이름 바꾸기, 또는 확장 단계 톱니바퀴에서 다시 |
| 도우미 쿼리가 데이터 창에 나온다 | 로드 사용이 켜져 있다 | 쿼리 오른쪽 클릭 → **로드 사용** 끄기 |
| 날짜 관계를 만들 수 없다, 배송일수 평균이 안 나온다 | 사용자 지정 열·조건 열의 형식이 없다(`ABC123`) | 열 머리글 형식 아이콘으로 날짜·정수·텍스트로 바꾼다 (2-6 끝) |
| 사용자 지정 열 결과가 Error | null 에 계산을 했다 (예: null - 날짜) | `if [열] = null then null else …` 로 감싼다 |

## 모델과 관계

| 증상 | 원인 | 해결 |
|---|---|---|
| 관계가 다대다(\*:\*)로 만들어진다 | 일(1) 쪽 열에 중복 값이 있다 | 차원 테이블의 키 중복을 Power Query 에서 제거 |
| 관계를 만들었는데 점선이다 | 같은 두 테이블 사이에 이미 활성 관계가 있다 | 정상. USERELATIONSHIP 으로 쓴다 (3-4, 4-6) |
| 행렬의 측정값이 모든 행에서 같다 | 행에 놓은 필드의 필터가 측정값 테이블까지 흐르지 않는다 (다 → 일 방향) | 필터가 닿는 테이블로 측정값을 만들거나 CROSSFILTER (3-6, 4-5) |
| 오른쪽 클릭 메뉴에 계층 만들기가 없다 | 메뉴 이름이 **계층 구조 만들기** 다 | 열 오른쪽 클릭 → 계층 구조 만들기 (3-7) |
| 시간 인텔리전스 결과가 비거나 이상하다 | 날짜 테이블로 표시를 안 했다, 날짜 테이블에 빠진 날이 있다 | 날짜 테이블로 표시, CALENDAR 로 빠짐없이 만든다 |

## DAX

| 증상 | 원인 | 해결 |
|---|---|---|
| VAR 가 있는 측정값이 구문 오류 | 변수 이름에 한글·빈칸을 썼다 | 변수 이름은 영문자·숫자·_ 만 (`VAR LateOrders = …`) |
| 수식 입력줄에서 Enter 를 눌렀더니 식이 확정돼 버렸다 | 줄 바꿈은 Shift+Enter | Shift+Enter |
| "열 … 에 대한 단일 값을 확인할 수 없습니다" | 측정값에서 열을 집계 없이 썼다 | SUM, MAX 같은 집계 함수로 감싸거나 반복 함수(SUMX) 안에서 쓴다 |
| 비중 측정값이 100% 만 나온다 | REMOVEFILTERS 가 행에 놓은 필드의 테이블을 없애지 않는다 | 행 필드의 테이블을 REMOVEFILTERS 에 넣는다 (4장 확인 문제 2) |
| 전년 대비 성장률이 수십만 % | 비교 기간(2016년)의 값이 아주 작다 | 시각적 개체 필터로 분석 기간 제한 (5-4) |

## 보고서

| 증상 | 원인 | 해결 |
|---|---|---|
| 드릴다운 화살표가 안 보인다 | 축에 필드가 하나뿐이다 | 축에 계층(또는 열 2개 이상)을 넣는다 |
| 드릴스루 메뉴가 안 나온다 | 대상 페이지의 드릴스루 칸 필드가 이 차트에 없다 | 같은 필드(상품[카테고리])를 쓰는 차트에서 오른쪽 클릭 |
| 도구 설명 페이지 대신 기본 도구 설명이 뜬다 | 페이지의 **도구 설명으로 사용** 이 꺼져 있거나, 차트의 도구 설명 형식이 기본값 | 7-4 의 2번, 6번 확인 |
| 상위 N 필터에서 "값" 칸이 비어 있다 | 기준 측정값을 넣지 않았다 | 데이터 창의 측정값을 값 칸에 끌어 놓는다 |

## 보안·데이터베이스

| 증상 | 원인 | 해결 |
|---|---|---|
| 표시 방법(역할로 보기)에서 CROSSFILTER 측정값이 든 시각적 개체만 오류 | RLS 가 걸린 모델에서는 측정값 안의 CROSSFILTER·USERELATIONSHIP 을 쓸 수 없다 | 그 관계를 양방향 + **양방향으로 보안 필터 적용** 으로 바꾸고 일반 측정값을 쓴다 (8-3) |
| 역할로 보기를 해도 숫자가 같다 | 필터 식이 관계 방향상 측정값 테이블에 닿지 않는다 | 차원 테이블(주)에 필터를 건다 (8장 확인 문제 3) |
| PostgreSQL 연결에서 암호화 관련 오류 | 실습용 데이터베이스는 SSL 을 쓰지 않는다 | "암호화된 연결 사용 안 함" 확인 창에서 확인 |
| 암호를 고쳐 넣어도 같은 인증 오류가 계속 난다 | 처음 입력한 (잘못된) 자격 증명이 저장되어 있다 | 홈 → 데이터 변환 ▾ → **데이터 원본 설정** → 그 원본 선택 → **권한 지우기** |
| `docker compose up` 후 Power BI 가 연결하지 못한다 | 아직 CSV 를 불러오는 중이다 | `docker compose ps` 가 healthy 일 때까지 기다린다 |
| 포트 5435 를 이미 쓰고 있다는 오류 | 다른 프로그램이 5435 를 쓴다 | docker-compose.yml 의 `"5435:5432"` 를 `"5436:5432"` 처럼 바꾸고 서버도 `localhost:5436` 으로 |
