# 부록 B. 용어 풀이 (심화)

기초 과정의 용어(측정값, 필터 컨텍스트, 관계, 카디널리티 등)는 기초 교안 부록 B 를 보자. 여기에는 심화 과정에서 새로 나온 용어만 모았다.

| 용어 | 뜻 | 나온 곳 |
|---|---|---|
| **매개 변수** (parameter) | 여러 쿼리가 함께 쓰는 이름 붙은 값. 파일 경로처럼 바뀔 수 있는 값을 한 곳에 둔다 | 1장 |
| **M** | Power Query 의 식 언어. 적용된 단계 하나가 M 식 하나 | 1장 |
| **QuoteStyle** | CSV 에서 따옴표를 어떻게 읽을지. `Csv` 면 따옴표 안의 줄 바꿈을 값의 일부로 읽는다 | 2장 |
| **쿼리 병합** (merge) | 키 열로 짝을 지어 다른 쿼리의 열을 붙이는 작업. 엑셀의 VLOOKUP 과 비슷하다 | 2장 |
| **조인 종류** | 병합할 때 어떤 행을 남길지. 왼쪽 외부, 내부, 왼쪽 앤티 등 | 2장 |
| **로드 사용 안 함** | 쿼리를 Power Query 안에서만 쓰고 모델에는 넣지 않는 설정 | 2장 |
| **조건 열** | 대화 상자로 만드는 if … then … else 열 | 2장 |
| **사실 테이블 / 차원 테이블** | 일어난 일(주문, 결제)을 기록한 표 / 그 일을 설명하는 표(상품, 판매자, 날짜) | 3장 |
| **필터 방향** (크로스 필터 방향) | 관계를 따라 필터가 흐르는 방향. 기본은 일(1) → 다(\*) 단일 방향 | 3장 |
| **비활성 관계** | 모델에 있지만 평소에는 쓰지 않는 관계(점선). USERELATIONSHIP 으로 켠다 | 3장 |
| **계층** (hierarchy) | 지역 → 주, 연도 → 분기 → 월 처럼 위아래가 있는 열 묶음 | 3장 |
| **측정값 테이블** | 측정값만 모아 두는 테이블 (_측정값) | 3장 |
| **CALCULATE** | 필터를 바꾼 다음 식을 계산하는 함수 | 4장 |
| **REMOVEFILTERS** | 테이블이나 열에 걸린 필터를 없앤다 | 4장 |
| **VAR / RETURN** | 식 안에서 중간 결과에 이름을 붙이고(VAR), 최종 결과를 돌려준다(RETURN) | 4장 |
| **CROSSFILTER** | 측정값 안에서만 관계의 필터 방향을 바꾼다 | 4장 |
| **USERELATIONSHIP** | 측정값 안에서만 비활성 관계를 켠다 | 4장 |
| **반복 함수** (iterator) | SUMX, AVERAGEX, FILTER 처럼 표의 행을 하나씩 돌며 식을 계산하는 함수 | 5장 |
| **컨텍스트 전환** | 반복 중인 행의 값이 CALCULATE(측정값) 안에서 필터로 바뀌는 일 | 5장 |
| **시간 인텔리전스** | TOTALYTD, SAMEPERIODLASTYEAR, DATEADD 처럼 날짜 필터를 다른 기간으로 바꾸는 함수 | 5장 |
| **YTD** (Year To Date) | 그해 1월 1일부터 지금까지의 누계 | 5장 |
| **시각적 개체 필터** | 그 차트 하나에만 걸리는 필터 | 5장 |
| **분산형 차트** | 두 측정값을 X·Y 축으로 놓아 점으로 그린 차트. 관계를 볼 때 쓴다 | 6장 |
| **드릴다운 / 드릴업** | 계층의 아래 수준으로 파고들기 / 위로 돌아가기 | 7장 |
| **상위 N 필터** | 측정값 기준으로 위(또는 아래)에서 N 개만 남기는 필터 | 7장 |
| **조건부 서식** | 값에 따라 셀 배경색·글꼴색·막대·아이콘을 바꾸는 서식 | 7장 |
| **도구 설명 페이지** | 마우스를 올리면 뜨는 작은 보고서 페이지 | 7장 |
| **드릴스루** | 항목 하나를 골라 그 항목으로 걸러진 상세 페이지로 넘어가기 | 7장 |
| **책갈피** | 보고서 화면 상태를 저장해 두고 단추로 불러오는 기능 | 7장 |
| **행 수준 보안 (RLS)** | 역할마다 볼 수 있는 행을 DAX 필터 식으로 제한하는 기능 | 8장 |
| **역할로 보기** | Desktop 에서 역할이 걸린 상태를 시험해 보는 기능 | 8장 |
| **성능 분석기** | 시각적 개체마다 계산·그리기에 걸린 시간을 재는 창 | 8장 |
| **커넥터** | Power BI 가 데이터 원본(PostgreSQL 등)에 연결하는 부품 | 10장 |
| **네이티브 쿼리 / 쿼리 폴딩** | 데이터베이스가 직접 이해하는 SQL / Power Query 단계를 SQL 로 바꿔 데이터베이스에서 계산하게 하는 일 | 10장 |
| **뷰** (view) | 데이터베이스에 저장해 둔 SELECT 문. 표처럼 불러올 수 있다 | 10장 |
| **가져오기 / DirectQuery** | 데이터를 .pbix 에 복사 / 볼 때마다 데이터베이스에 질의 | 10장 |
| **헤알 (R$)** | 브라질의 화폐 단위. 이 교안의 금액 단위 | 0장 |
